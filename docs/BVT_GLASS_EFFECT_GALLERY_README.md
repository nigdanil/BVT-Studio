# BVT Studio — Visual Glass Gallery v0.1

## Purpose

Generate 13 *separate*, editable Blender 5.2.3+ `.blend` scenes, matching PNG renders and independent four-pane glass overlays on one original 1672×941 freezer photo. Each launched Blender process begins with `--factory-startup`. Source image is **packed** in each `.blend`; generated atlases and test masks are packed too.

**These masks are approximate test-only rectangles, not verified glass segmentation or ground truth.** The script does not create YOLO annotations, modify the input, or establish photorealism/ML gains.

## Setup (Git Bash)

Unpack this archive **into `D:\BVT-Studio`**, preserving `scripts/`, `configs/`, `docs/` subfolders. Do not overwrite unrelated source files. Script uses BVT Studio's existing API and leaves the add-on unchanged.

```bash
cd /d/BVT-Studio
bash scripts/run_bvt_glass_gallery.sh
```

Update the `PHOTO` path in `scripts/run_bvt_glass_gallery.sh` if the original photo moved. Expected reference image size: **1672 × 941**. For another photo/layout, edit `configs/bvt_freezer_glass_rects_1672x941.json` in top-left pixel coordinates and its `reference_size`. Four window areas are approximations; verify manually in camera view.

The command stops on the first failing mode (`set -euo pipefail`), so results are not silently considered complete. Re-run after correcting the problem; separate variant directories are reused and `scene.blend1` backups may be generated by Blender when overwriting files.

## Effects

1. `00_clean`: transparent control
2. `01_light_condensation`: procedural light wetness
3. `02_heavy_condensation`: procedural heavy wetness
4. `03_frost`: crystalline frost
5. `04_dirty_glass`: contamination
6. `05_reflections`: LED reflections
7. `06_micro_droplets`: small-scale procedural water beads
8. `07_atlas_light_no_optics`: generated atlas LIGHT, optics disabled
9. `08_atlas_light_optics`: same LIGHT atlas with optics enabled
10. `09_atlas_medium_no_optics`: generated MEDIUM atlas, optics disabled
11. `10_atlas_medium_optics`: same MEDIUM atlas with optics enabled
12. `11_atlas_heavy_streaks`: HEAVY atlas with streaks
13. `12_atlas_strong_optics_stress`: optical stress reference (not an accepted preset)

## Where are mask paths?

`masks/mask_glass_001.png` ... `004.png` in each variant folder. These are imported, applied to each pane, and **packed into the `.blend`**. In BVT Studio panel, selecting `Glass_p_001` and looking at 'Assigned' should show a mask; a blank path field does not mean the packed assignment is missing. Source paths are only needed when re-importing/replacing a mask.

`Alpha / Height / Normal PNG` fields should be **left empty for REALISTIC_ATLAS**: the atlas generator produces and packs its own maps. For `PHOTO_MAPS`, specify three same-resolution PNGs from an external source and then click **Import & Pack Droplet Maps**.

### Optional: use custom verified glass masks

For a source photograph, prepare 4 genuine segmentation masks in glass-plane UV space, all grayscale PNGs with matching orientation; paths:

```text
D:/MyMasks/mask_glass_001.png
D:/MyMasks/mask_glass_002.png
D:/MyMasks/mask_glass_003.png
D:/MyMasks/mask_glass_004.png
```

Edit the shell script's Blender command and append `--mask-dir 'D:/MyMasks'`. The script imports and packs those; **it cannot verify their correctness**. To turn off external PNG masks entirely, add `--no-mask` instead.

## Visual review

Compare each `render.png` to `00_clean/render.png`. For the same atlas density, compare `optics` ON vs OFF; check no white ring halos, preserved label readability, plausible gravity streaks, no effects on metal frame, no transform drift and no crop difference. Open `scene.blend` in Blender then `Numpad 0` and `F12` to render. The source is packed so no external original path is required after scene creation.

## Important limitations

- Requires installed Blender 5.2.3 LTS and **the current BVT Studio source checkout**; generated `.blend` contains materials/properties but the add-on should be installed/enabled in GUI to use BVT controls.
- No actual Blender executable in the authoring environment: Python syntax was checked, but these new gallery scripts have to be **runtime-verified on your Windows Blender**. Existing BVT smoke tests have passed according to the user's logs.
- Excluding nonrectangular metal bars or reflections requires genuine per-pane pixel masks; auto-generated masks do not assert that.
- The `PHOTO` value in shell defaults to `C:/Users/danil/Desktop/3D/Done/BVT_Freezer_Planogram_16x9_v11_eng.png`.
- Save scenes in `qa_renders/`, not into source-controlled datasets; do not commit photos/large rendered assets accidentally.
